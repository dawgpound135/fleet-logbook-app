# Fleet Logbook App

This application tracks a fleet using an Android app that relays trip data to an admin portal,
where the owner can track their trucks' mileage and pull a daily, weekly or monthly report for each truck and driver.
The driver app, web dashboard and API live in the same repo. The front ends are built with Vue, the backend with Node.js and Express, and the data is stored in PostgreSQL.

**Status:** work in progress.
